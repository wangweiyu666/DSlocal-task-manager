# 手工验收样例

本目录保存供模拟器或真机手工导入的 DST1 样例，不属于 `protocol-test-vectors/` 的自动化协议测试向量。

## test-import-2026-07-20.dst1

- 来源：W21/W22 开发期间生成；
- 用途：验证本地通知、今日任务列表、任务详情和执行交互；
- 覆盖：计时、计数、信息填写、每日重复、步骤、积分组及提醒；
- 数据仅用于测试，不包含真实用户任务。

导入前请注意：样例中的显式任务日期为 `2026-07-20`，重复任务也从该日开始。重复导入同一批次时，应用会按既有 DST1 导入规则处理。

## w24-manual-2026-07-22.dst1

- 来源：W24 当日结果与图片分享手工验收；
- 用途：验证今日结果、纯文本复制、结果图片、信息告知正文复制与分享图片；
- 覆盖：两个积分组、未分组任务、普通任务、步骤、点击计数、短计时、信息告知，以及导入时已过期的必做任务；
- 建议流程：导入后完成“工作与学习”中的项目复盘和信息告知，再完成“健康习惯”中的计数与计时，保留“整理明日计划”为未完成，随后从今日页下拉查看混合状态结果。

该样例的显式任务日期为 `2026-07-22`，其中“整理明日计划”的截止时间为当天 `09:00`，用于稳定制造未完成状态。重复导入会被相同 `batchId` 阻止。
