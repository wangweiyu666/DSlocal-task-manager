# DStationery 产品规则

本文维护当前业务语义，不复述发布步骤或逐字段 Schema。协议见 [DST1 契约](dst1-test-vectors.md)，备份见 [DSTB1](dstb1-format.md)，验证范围见 [最小测试方案](minimal-testing.md)，已执行结果见 [历史记录](verification-records.md)。

## 产品与角色

| 产品 | 布置与执行 | 数据边界 |
| --- | --- | --- |
| 离线 Web / Android | 布置者生成任务码，执行者导入、执行并主动分享 | 不登录、不上传、不读取对方状态；Android 不声明网络权限 |
| 管理员 Web / production Android | 管理员发布并分配任务，执行者缓存、离线执行、联网同步 | 账号与空间授权；管理员只查看已提交结果，执行草稿和私人备注不上传 |

两种模式共用任务规则；离线模式的无账号、无服务器限制不适用于联网产品。执行者不能修改标题、描述、积分、归属、截止、步骤结构或重复规则；可填写执行答案和备注、确认/撤销完成、查看历史与积分。离线执行者通过任务码导入，联网执行者通过同步取得任务。

## 身份、定义与更新

批次、积分组、任务、步骤、选项使用稳定的 16 字符 Base64URL ID。批次 ID 标识一次导入，重复导入被阻止；复制任务生成新任务 ID，改名和排序保留原 ID。任务定义与实例分离：单次实例键为 `once`，重复实例为计划日期；云 occurrence key 另含修订与时区版本，见 [联网指南](connected.md#时区与实例)。

同一任务 ID 更新完整定义，可选字段省略恢复默认；已有任务省略 `y` 则保留原日期，只有显式且不同的 `y` 才移动日期。缺少 `i/n/r` 无效。普通更新不能重开已完成实例；再次执行应复制新任务，或由执行者按规则撤销完成。

已完成实例保留执行配置、答案、完成时间和实际得分快照。未完成实例更新时保留兼容进度；类型或目标改变清理不兼容输入并重新确认，信息要求改变保留草稿供重新检查。定义更新、日期/分组移动和撤销产生操作与结果版本，不删除历史。

积分组采用局部更新：字段省略保留原值，`cm/im` 空字符串恢复默认文案；未知组无名称时使用“未命名积分组”。任务放在 `g[].t` 即归入该组，放在顶层 `t` 即未分组。移动会转移历史积分归属并重算相关日期结果，但不重算实际已得分。无待完成任务且不再生成实例的组可以本地归档；同 ID 新任务解除归档，未分组不能归档。Web 删除本地配置不等于撤销执行端数据。

## 日期、截止与重复

- Android 任务日以 04:00 换日，默认截止为归属日期次日 04:00。日期 `YYYY-MM-DD`、本地日期时间 `YYYY-MM-DDTHH:mm`、重复截止钟点 `HH:mm` 必须有效且补零，不接受秒或时区后缀。
- 离线日期按本地墙上时间解释，改时区保留日期和钟点；联网计划按空间的版本化 IANA 时区解释。单调计时不受改系统时间影响；拨回时间不自动重开已错过实例。
- 首次导入省略 `y`：日期截止归其日期，精确截止早于 04:00 归前一天，否则归当天；没有可推导日期则归导入任务日。已有任务更新省略 `y` 保留原值。`l:null` 永不截止；省略 `l` 使用默认截止。
- Web 新任务日期、重复开始日期留空时，在布置时按自然日固定：离线取网页任务时区，联网取空间时区。旧任务日期未触碰保留旧语义，主动清空表示当天；精确截止模式留空仍无效，未知空间时区需刷新。
- 离线预览冻结日期、批次/步骤 ID、任务及例外载荷，任务码、历史与确认提交共用该快照；跨午夜不重算。修改草稿使旧预览失效。联网排队和重试使用已固定载荷。
- 重复支持每日或每周；每周日期 1～7 唯一且升序，每日无 `w`。结束日期与次数互斥；次数是实际实例总数，不是周数。两者均省略表示长期重复。
- 首次导入不补导入前日期；后续启动、导入和换日补建已发布后遗漏的实例，只生成到当前任务日。过期补建直接错过，计入次数。模板更新不重置次数，未来实例用新定义；当前已生成实例按可更新状态和单日例外处理。
- 撤销模板停止未来生成；重新启用不补撤销期间日期，期间不消耗次数。已生成实例仍计数，已过结束日期不再生成。

### 单日例外与延期

DST1.1 的 `e` 按任务 ID＋计划日期覆盖重复任务；同日新指令完整替换旧例外，字段省略继承有效模板。只含 `i/y` 清除例外，`c:1` 单日撤销且不与覆盖字段共存。例外不能改 ID、分组、计划日或重复规则，完整覆盖结果必须通过校验。

撤销日生成 CANCELLED 实例且消耗一次计划次数，不补偿额外日期、不计分。未生成的过去日期不回填；已生成日期即使不再属于最新规则也可命中。已完成历史不变；已错过实例只接受撤销或未来截止重开。

单次延期使用同任务完整新版及未来截止，保留原归属日期和兼容进度；已完成不会重开。重复某次延期为新的临时任务：复制定义、去掉重复规则、生成新 ID；原实例维持原结果，两者独立计分。

## 执行状态

| 状态 | 进入与操作 |
| --- | --- |
| NOT_STARTED / 未开始 | 尚未到任务日开始；不能执行，可写备注 |
| PENDING / 待完成 | 可编辑执行输入并主动完成；到截止转 MISSED |
| COMPLETED / 已完成 | 执行只读；撤销完成后按截止转 PENDING 或 MISSED |
| MISSED / 未完成 | 不可继续执行，布置者延期至未来才重开 |
| CANCELLED / 已撤销 | 不参与结果；重新导入有效定义后按时间恢复 |

布置者撤销不会删除历史，已完成实例保持完成与计分；重复模板停止未来生成。任务更新与撤销列表不得包含同一任务 ID。没有截止时间不会自动错过。

## 执行类型与自动保存

`r=1` 必做、`r=0` 选做，与执行类型独立。达标只允许完成，任何类型都不自动完成整项。

| 定义 | 执行要求 |
| --- | --- |
| 省略 `u` | 直接完成 |
| `k=1` 计数 | `a=1` 拖动 / `a=2` 点击，目标 1～999，进度 0～目标；允许减一纠错 |
| `k=2` 计时 | 目标 1～3600 秒，毫秒累计；仅前台运行，可暂停续计，离页/后台/锁屏暂停；重启不自动继续 |
| `k=3` 信息告知 | 执行者填写非空正文，最多 2000 码点；与私人备注分开保存 |
| `k=4` 心情 | 五档整数 1～5，无默认选择；选填感受最多 2000 码点，档位不改变基础积分 |
| `k=5` 分步骤 | 1～50 个稳定 ID 步骤，遵循顺序与条件规则 |
| `k=6` 通知 | 布置者提供非空正文，最多 2000 码点；执行者点击“确认已知晓” |
| `k=7` 单选积分 | 2～50 个选项，无默认选择；名称 1～100 码点，选项积分 0～9999 的整数 |

信息与心情正文停止输入 500ms 自动保存；心情档位和单选选择立即保存。确认、完成、离开页面前等待最新输入写入成功，旧异步结果不能覆盖新输入；失败保留输入和重试入口并阻止确认或完成。清空可保存为空草稿，信息为空仍不能完成。

计时每次只运行一个，保存失败保留待写进度，重试不能重复累计。已完成只读；撤销保留兼容答案。每日实例互不复制输入。普通备注任何状态可编辑，只在本机，既不随任务码传输，也不随结果上传或分享。

心情图标、许可见 [资源说明](mood-artwork.md)。信息正文可复制或单独生成图片；调用系统分享不代表任务完成，不能判断是否真正发送。告知长图不截断正文，资源上限不允许时应报错；通用结果图不显示信息或心情正文。

## 步骤与条件分支

步骤包含稳定 `i`、名称 `n`、必需标志 `r`，可用叶子 `u`（1～4、6、7）或省略表示直接确认；不能嵌套 k=5。排序和改名不更换身份。旧无 ID 步骤继续按旧任务语义读取；只在明确编辑转换时生成确定性 ID，不在数据库升级时自动转换。

条件 `c:{s:前置步骤ID,o:选项ID}` 只能引用同任务前面的一个单选步骤和其中一个选项。每步最多一个条件，多个步骤可引用同一选项，分支内单选可控制后续步骤；不支持跨任务、向后引用、多条件组合或容器嵌套。删除、移动被引用项前必须修正关联；日期例外应用后也验证完整定义。

只有前置选项已确认且匹配时分支才适用。未确认为 WAITING，条件不符、前置跳过或前置不适用为 NOT_APPLICABLE；两者不能混同。执行者只看到当前适用步骤，按原顺序执行；进度只统计适用步骤。

步骤状态为 PENDING、CONFIRMED、SKIPPED、NOT_APPLICABLE。选做才可主动跳过，达标后仍须手动确认。已确认单选须撤销后改选；从撤销位置起重置后续确认/跳过，保留兼容草稿。切回原分支可以恢复草稿，但必须重新确认。重排从首个受影响位置重新确认，删除已选选项清除该选择。

整项完成先在同一事务跳过剩余选做步骤并重算分支；仍有适用必需步骤未确认则拒绝。页面完成按钮使用同一规则，不能把等待前置选择当成分支不适用绕过完成条件。整项完成锁定执行；整项撤销保留步骤状态和答案，执行权限仍受任务状态/截止限制。

## 积分与每日结果

整项完成一次结算 **基础积分＋适用且已确认的选项积分**；独立单选按已提交选项计算。各项积分为 0～9999 非负整数，无小数；草稿、跳过和不适用选项不计分，步骤不单独生成到账。必做、选做和重复的每个实例均可计分。

保存、同步重试和重复点击不能重复到账。撤销完成按原实际到账金额生成负流水，再次完成按新提交生成正流水；历史流水不删除。更新配置不改历史实际得分，移动日期或分组只调整归属及相关结果。

每日按组及全局计算：有必做错过→未完成；否则有待完成必做→进行中；必做全完成→完成；只有选做→选做记录；没有有效任务→无结果。CANCELLED 不参与；布置者撤销但仍保持 COMPLETED 的实例继续参与。组用 `cm/im`，全局用内置文案。

过去日期新增、延期、重开、修改必做、移动或撤销会重算受影响结果并追加版本（时间、前后状态、批次、任务和原因）。累计统计从实际流水计算，不把缓存作为恢复依据。

## 页面、排序与分享

Android 底部为“历史｜今日｜我的”，默认今日；二级页返回上层，弹窗/表单优先关闭，首页返回退出。今日按每日、每周、临时再按组分类：每周规则含 4～7 天归每日，1～3 天归每周；分类作为实例快照，空分类隐藏。各分类＋组默认显示前 3 项，其余可展开。

默认任务排序为必做优先、截止较早、无截止、首次导入顺序；人工 `o` 优先，无 `o` 排其后，移除 `o` 恢复默认。组按首次出现顺序。今日与结果使用同样任务排序。

今日列表顶部继续下拉打开当日结果，未达阈值回弹，向上滑或返回关闭。结果显示任务日、布置者、总状态、实际净积分、各组任务状态和文案；不显示撤销实例、内部 ID、备注、描述、执行正文或日志。生成不改变任务，可重复复制/分享；不生成历史整日分享图。

历史按任务日倒序，支持日历、名称搜索、组/状态筛选、分页及结果版本；详情展示当时执行快照，备注仍可编辑，信息正文只读可再次分享。“我的”含总/本日积分、完成数、7/30 日趋势、组及流水、归档组。必做完成率分母为已开始的完成＋错过＋待完成必做，分子为已完成；未来、撤销、选做不计，无分母显示“—”。

设置含主题、减少动画、通知和隐私提示、关于；字号跟随系统，主题不改变分享图，不允许更改任务日边界或任务内容。提醒被拒绝不影响执行，不反复索取权限。定时提醒 `h` 最多 5 个、0～10080 分钟、唯一降序，只安排发布后且仍在未来的提醒，不补发、不申请精确闹钟；通知只给出必做/选做摘要，无任务正文或快捷完成。

Web 支持任务库、组、模板、草稿、导入导出和移动布局，编辑单选的排序/删除操作须分行可达。离线 Web 生成冻结批次，联网 Web 发布不可变修订、管理分配并展示提交结果；两者通过独立入口、构建和存储边界区分，不能声称离线 Web 可读取执行状态。

## 持久化、备份与边界

AppDatabase 当前为 Room 9，保持连续迁移与实例快照；8→9 增加通知/选项配置、条件、选择和实际得分，旧完成按原积分迁移，旧任务不自动转换。联网另有独立同步库与会话保护，不能混用库版本。

DSTB1 外层版本 1、业务 payload 5，继续读取 1～4；保存定义、实例、执行草稿/答案、条件、实际得分及流水。合并按来源选择完整实例和步骤，不能逐条混合不同分支版本；新撤销不被旧完成覆盖。完全替换恢复可迁移设置，合并保留本机设置；失败整批回滚，计时恢复暂停，通知重建且不补发。格式、限额和冲突规则只在 [备份规范](dstb1-format.md) 维护。

离线产品无账号同步，联网产品按空间隔离结果；均不提供任务码数字签名或自动动作识别。联网不提供端到端加密、远程推送或 DSTB1 云迁移；角色导出和账号删除见 [隐私说明](../PRIVACY.md)。用户导出的备份和分享可能含正文，应明确提示，不能加入遥测或诊断日志。
