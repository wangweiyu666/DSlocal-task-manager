# W33 UI 配色选择实现说明

> 前置：W26、W32
> 协议：保持 `DST1` / `v=1`
> 数据库：保持 Room v1.5，无 migration

## 已实现

- 设置页“外观”区域新增“配色”，以两张四色预览卡提供“靛紫 / 晴空”选择；
- 配色与“跟随系统 / 浅色 / 深色”相互独立，点击后立即全局生效；
- 现有用户、新安装和损坏设置均安全回退到“靛紫”；
- 两套配色各自提供浅色和深色 ColorScheme，继续关闭 Material You 动态取色；
- 分享图片保持固定浅色布局，但主色和状态强调跟随当前配色；应用图标不随设置变化。

## 色彩语义

“晴空”使用：

| 颜色 | 用途 |
| --- | --- |
| `#78A4CB` | 主色、主要按钮、选中状态与重点数据 |
| `#95BDD7` | 次级强调与待完成状态 |
| `#B4E1EB` | 选中容器、标签及浅色强调背景 |
| `#F9E8A2` | 第三强调、少量提示与图表区分 |

错误色在浅色主题使用 `#B9505A`，深色主题使用 `#FFB3B8`。红色只用于操作失败、高风险操作、明确未完成和负积分；通知未开启等普通状态改用中性色。状态仍同时提供文字或图标，不依赖颜色单独表达。

## 设置与备份边界

- 选择写入现有 `SharedPreferences` 的 `ui_palette`，不修改 Room 或 DST1；
- 本次按最小改动原则不修改 DSTB1 格式，也不将配色加入可迁移设置；
- 恢复旧备份不会改变当前本机配色。未来如需跨设备迁移，应在独立窗口设计 DSTB1 向后兼容字段。

## 定向验收

- 设置仓储覆盖默认值、持久化与损坏值回退；
- Compose 测试覆盖“晴空”选择回调；
- 分享图片测试覆盖“晴空”主色映射；
- Preview 截图覆盖“晴空”浅色与深色设置页；
