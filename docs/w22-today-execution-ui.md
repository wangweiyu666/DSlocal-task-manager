# W22 今日执行 UI 实现说明

> 前置：W10、W11、W20
> 协议：保持 `DST1` / `v=1`
> 数据库：保持 Room v3

## 已实现

- 今日页按“每日任务、每周任务、临时任务”分类，并在分类内按积分组展示；
- 积分组沿用首次出现顺序，未分组任务独立展示；任务支持人工 `sortOrder` 与默认必做、截止、导入顺序；
- 每个“分类＋积分组”区块超过 3 项时默认折叠，并可独立展开或收起；
- 已撤销实例不出现在今日列表，但数据库、审计与后续历史入口不受影响；
- 今日页提供加载、错误、重试、空状态及右下角圆形 DST1 导入按钮；
- 点击任务进入独立详情页，详情路由可供 W21 通知深链复用；
- 详情页接入步骤、滑动/点击计数、前台计时、信息告知草稿、完成及撤销完成；
- 计时离开页面、切换应用或锁屏时自动暂停，运行时保持屏幕常亮；
- 完成后执行数据锁定并显示任务完成提示；撤销完成前说明积分和截止状态影响并二次确认；
- 普通备注与告知正文独立保存，允许所有任务状态编辑；输入停止 500ms 后自动保存，离页时立即提交，并显示保存状态；
- ViewModel 持有页面状态，Composable 不访问 DAO；执行写入继续调用 W10 `TaskExecutionService`。

## 视觉与交互基线

- 使用克制的 Material 3 单列布局、紧凑任务卡和固定底部主要操作；
- 关闭 Android 动态取色，所有系统主题统一使用以 `#6366F1` 为主色的内置浅色/深色色板；
- 字体统一通过 `MaterialTheme.typography` 注入并使用系统主题字体，不在页面内固定字体族；
- 展开收起、状态变化和页面切换仅使用 150～220ms 的功能性动效；
- 状态同时使用文字与颜色表达，不以颜色作为唯一提示；支持系统字体缩放与明暗主题。

应用只跟随系统浅色/深色模式与系统字体，不再跟随壁纸主题色。
