# W11 重复任务与实例生成实现说明

> 前置：W00、W01、W10  
> 协议：保持 `DST1` / `v=1`  
> 数据库：保持 Room v1.3

## 已实现

- 将 `x.f=1/2` 解析为强类型每日/每周重复规则；
- 首次导入从当前任务日开始，不补建导入前实例；
- 使用 `(taskId, ISO 计划日期)` 作为重复实例联合主键；
- 使用纯 `RecurrencePlanner` 处理开始、结束、次数和星期规则；
- 使用批量 `COUNT + MAX` 获取生成摘要，不加载全部历史实例；
- 使用小范围 occurrence key 查询和 `INSERT IGNORE` 提供最终幂等保障；
- 应用启动、恢复前台和导入后补建截至当前任务日的实例；
- 离线补建的过期实例直接标记为 `MISSED`；
- 实例保存任务、步骤、执行方式、积分和提醒配置快照；
- 模板更新不改变已生成实例，新实例使用最新模板；
- 撤销停止生成并取消未结束实例，恢复时跳过撤销期间；
- 单次/重复互换时保留旧实例，并取消与新模板竞争的活动实例；
- W10 的计数、计时、告知、完成与积分服务直接支持日期实例键；
- 导入预览复用正式 Planner，显示即将生成的 occurrence 日期。

## 日期与截止规则

- `x.s` 缺失时保存首次导入任务日；显式过去日期首次导入时也不会触发历史补建；
- `x.e` 包含当天；`x.c` 按历史实际生成实例总数限制；
- 每周掩码 bit 0～6 对应周一～周日；
- 缺失 `x.t` 为计划日期次日 04:00；`null` 为永不截止；
- 明确的 04:00 及更早凌晨时间归到计划日期次日；
- occurrence key 一旦生成，不随时区或系统时间变化。

## 性能策略

应用前台同步先对所有活动模板执行一次分组统计：

```sql
SELECT taskId, COUNT(*), MAX(taskDate)
FROM task_instance
WHERE taskId IN (...) AND occurrenceKey != 'once'
GROUP BY taskId
```

Planner 只计算最后生成日期之后到当前任务日的小范围，并仅查询该范围内的键。实例表仍是真实来源，不在定义表维护易失真的计数缓存。
