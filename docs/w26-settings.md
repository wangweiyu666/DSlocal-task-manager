# W26 独立设置页面实现说明

> 前置：W21、W24、W25
> 协议：继续使用 `DST1` / `v=1`
> 数据库：继续使用 Room v5，无 migration

## 页面与导航

- “我的”标题右上角提供齿轮设置入口，加载、空状态和错误状态下均可进入；
- 设置页使用独立路由，顶部显示返回按钮和“设置”标题，不显示底部导航；
- 返回后保留“我的”页面原有统计周期、状态和滚动位置；
- 设置页由 Navigation Compose 提供预测式返回；返回图标复用全局 UI 组件；
- “我的”页底部原任务提醒卡片已移除，通知设置只在独立设置页出现。

设置页按以下顺序纵向展示：

1. 外观；
2. 辅助体验；
3. 通知；
4. 隐私与分享；
5. 关于。

## 本地设置

W26 使用统一的 `SharedPreferences` 设置仓储，不将本机偏好写入 Room：

| 设置 | 默认值 | 行为 |
|---|---|---|
| 主题模式 | 跟随系统 | 可选跟随系统、浅色、深色，立即全局生效 |
| 减少动效 | 关闭 | 关闭页面切换、展开和统计数值补间等非必要动画 |
| 最近统计周期 | 近 7 日 | “我的”页切换后自动记住，不在设置页重复提供选项 |
| 分享隐私确认 | 未确认 | 可在设置页重置，使下次信息告知图片分享重新提示 |
| 通知权限已请求 | 否 | 用于区分首次申请与跳转系统通知设置 |

旧版 `notification_settings/permission_requested` 和
`share_preferences/information_privacy_confirmed` 会在首次创建统一仓储时迁移，已有用户状态不会丢失。未知或损坏的枚举值回退到安全默认值。

普通 DST1 导入不得读取或修改这些偏好。W31 完整备份恢复再负责携带设置。

## 外观与动效

- 主题继续使用固定色板，不读取 Material You 动态颜色；
- 浅色、深色和跟随系统只改变应用界面，分享图片始终使用固定浅色样式；
- 字体和字号始终跟随系统，设置页只显示说明，不提供字体选择器；
- 减少动效开启后，页面导航、今日结果切换、列表展开、详情内容尺寸变化、统计数字和进度直接切换；
- 滑动、滚动、按钮状态反馈和结果页直接操作手势保持可用；
- 未开启应用内开关时仍尊重 Android 系统动画缩放设置。

## 通知

- 页面读取 Android 当前实际通知状态；
- Android 13 及以上首次主动点击时请求通知权限；
- 已请求或已关闭时打开应用专属通知设置；若入口不可用则退回应用详情页；
- 两级系统入口都不可用时留在设置页并显示错误提示；
- 提醒时间仍由导入任务中的 DST1 定义决定，设置页不允许编辑；
- 不提供与系统权限重复的应用内通知总开关。

## 隐私与关于

- 已确认信息告知分享提示时，可点击“下次分享时重新提醒”；
- 重置后下次分享信息告知图片重新显示隐私提醒，不删除任何任务、图片或历史数据；
- 关于区显示应用版本、DST1 v1、Room v5，以及数据仅保存在本机且应用不申请网络权限的说明；
- 不显示设备标识、数据库路径、构建路径或诊断日志。

## 测试交付

设置页面交付以下测试资产：

- 设置默认值、持久化、旧偏好迁移、异常值回退和隐私重置的 JVM 测试；
- 设置选择、减少动效、隐私重置及“我的”设置入口的 Compose 仪器测试；
- “我的”设置入口、设置页浅色、深色和大字体共 4 张 Preview 截图基线；
- API 35 完整流程和 API 26 关键兼容流程测试入口。

最终回归结果：87/87 项 JVM 测试、14/14 项 Preview 截图、API 35 的 20/20 项仪器测试，以及 API 26 的 8/8 项 UI 兼容测试通过；Debug APK 与仪器测试 APK 构建成功。API 35 回归包含从设置页通过系统返回恢复“我的”页面。
