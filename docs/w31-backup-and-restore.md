# W31 DSTB1 备份与恢复实现说明

> 前置：W21、W25、W26
> 文件格式：DSTB1 v1
> 数据库：继续使用 Room v1.5，无 migration

## 页面与导航

- 设置页新增“数据与备份”，进入独立“备份与恢复”路由；
- 页面提供“导出备份”和“恢复备份”，不显示底部导航；
- 导出使用系统创建文档界面，预填 `本地任务备份_yyyyMMdd_HHmm.dstb`；
- 恢复使用系统打开文档界面，文件扩展名不是校验依据；
- 选中文件后先完成文件头、版本、长度、CRC32、JSON 和业务引用校验，校验前不修改数据库；
- 恢复默认选择“合并恢复”，也可选择“完全替换”；
- 完全替换只显示一次明确确认，不要求输入确认文字；
- 合并中的同时间戳冲突默认保留本机，可逐项或批量采用备份；
- 进度页可以返回，WorkManager 继续执行；恢复期间其他业务页面进入临时只读状态；
- 结果页保留到用户主动完成，恢复成功后返回“今日”。

页面沿用固定主题、系统字体、减少动效和预测式返回。底部按钮不使用固定高度，结果页截图资产使用 100% 字体。

## 文件与数据范围

二进制格式由 [`dstb1-format.md`](dstb1-format.md) 定义。文件使用 UTF-8 JSON、zlib 和 CRC32，不设置密码且不加密。首次导出前单独提示：持有文件的人可以读取任务、告知正文、备注和积分记录。提示确认可在备份页重置，不与分享图片提示共用状态。

备份覆盖 Room v1.5 中除 `reminder_record` 外的 13 张业务表：

- `app_profile`、`import_batch`；
- `task_group`、`task_definition`、`task_step_definition`；
- `task_instance`、`instance_step`、`execution_progress`；
- `information_submission`、`task_note`；
- `points_ledger`、`action_log`、`result_revision`。

可迁移设置只包含主题模式、减少动效和最近统计周期。以下内容不进入文件：

- 分享与备份的隐私确认状态；
- 通知权限请求状态、通知渠道和 `reminder_record`；
- 图片、截图、相册文件、缓存和 APK；
- 设备名称、型号、账号和外部文件路径。

正在运行的计时器只保存数据库中已累计的时长，恢复后不自动开始计时。任务日期与截止时间保持本地日历含义；历史事件时间保留 Epoch 毫秒值。

## 导出

- Room 事务读取稳定排序的一致快照，快照之后的修改不进入本次文件；
- 后台任务生成完整内部文件后再复制到用户选择的位置；
- 写入完成后重新读取目标，校验长度、内容和 CRC32；
- 复核失败时尝试删除不完整目标，不报告成功；
- 同一时间只存在一个 W31 后台任务，导出期间暂停新的 DST1 导入，但普通任务操作保持可用；
- 页面只记录最近一次成功导出时间，不保存文件名或路径。

## 合并恢复

合并先在内存中生成完整计划，再于一个 Room 事务中写入：

| 数据 | 规则 |
|---|---|
| 积分组、任务定义、任务实例 | ID 或 `taskId + occurrenceKey`相同者采用 `updatedAt`较新版本 |
| 步骤、计数、计时、告知、备注 | 各自独立比较，不随父记录整体覆盖 |
| 同时间戳不同内容 | 默认本机，进入冲突页允许选择备份 |
| 导入批次 | 按 `batchId`去重 |
| 积分流水、操作日志、结果版本 | 唯一 ID 和内容相同则去重；ID 相同而内容不同则拒绝整个合并 |
| 个人称呼 | 保留本机；本机为空时采用备份 |
| 应用设置 | 合并不修改本机设置 |
| 通知 | 不合并，恢复后重建 |

冲突页只展示可读名称和字段差异，不显示原始 JSON、UUID 或数据库术语。

## 完全替换与回滚

恢复前在应用内部生成完整 DSTB1 回滚快照并写入未完成标记。数据库清理与写入使用 Room 事务；设置只在数据库成功后应用。任一数据写入、周期实例补生成或结果重算失败时，自动恢复数据库和可迁移设置。

如果进程或设备在恢复中断开，下次启动由恢复 Worker 读取内部快照，在开放业务操作前还原。成功后删除快照；普通临时文件成功、失败后立即清理，遗留文件超过 24 小时后清理。

恢复后：

1. 按当前任务日补生成有效周期实例；
2. 从任务实例与积分流水重新计算当前统计和结果，不因恢复新增结果修订；
3. 保留备份中的历史结果版本；
4. 新增一条不含路径和文件名的 `BACKUP_RESTORED` 操作记录；
5. 重建未来提醒，错过的提醒不补发。

提醒调度因权限或系统限制失败时不回滚已恢复数据，下次启动重试并在结果页提示。

## 安全限制

- 外部文件最大 100 MB，解压 JSON 最大 500 MB；
- 元数据最大 1 MB；
- 文件头声明长度、实际长度和 CRC32 必须全部一致；
- 重复主键、缺失引用、无效日期、负进度、越界积分及不合理内部时间关系均拒绝；
- 计划日期允许在未来；历史事件允许相对快照时间最多 5 分钟时钟误差；
- 较新且未知的格式版本提示升级应用，不尝试部分恢复；
- CRC32 只用于损坏检测，不代表文件可信或防篡改。

- 合并的新旧时间、同时间戳选择和不可变 ID 碰撞 JVM 测试；
- Room 快照与替换失败事务回滚 JVM 测试；
- 首页、恢复方式和冲突选择 Compose 仪器测试；
- 备份首页、恢复预览、冲突处理和 100% 字体结果页 4 张截图基线；
- 最小合法、完整合法和损坏文件测试向量。
