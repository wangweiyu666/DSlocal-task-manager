# Android 当前实现边界

当前版本为 `0.1.0-alpha`，协议为 DST1 v1，数据库为 Room v3。完整进度见[实施状态与路线图](android-phase-1-summary-and-roadmap.md)。

## 已具备

- 严格解析、预览并以单事务导入 DST1；
- 持久化 Dom、批次、积分组、任务定义、实例、步骤和执行进度；
- 支持普通、步骤、计数、计时、信息告知和重复任务；
- 支持完成、撤销、未完成校准、积分流水和每日结果重算；
- 支持延期、重新开启、跨积分组迁移和显式日期迁移；
- 支持既有 `h` 的本地隐私通知、权限控制和系统事件重建；
- 提供今日分类、任务详情、完整执行及导入流程。

## 尚未形成产品界面

- 完整历史和统计页面；
- 信息告知分享图；
- 备份、恢复与诊断界面。

能力从“未实现”变为“已实现”不要求升级 DST1；只有线格式或业务语义出现不兼容变化时才升级协议主版本。

## 持久化兼容

Room 已冻结为 v3，并提供 `1→2→3` 显式迁移。后续结构变更必须同时提交连续 migration、导出 Schema、数据保留测试，并更新[数据库规范](android-database-v3.md)。
