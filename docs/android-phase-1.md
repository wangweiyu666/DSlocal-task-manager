# Android 当前实现边界

当前版本为 `0.1.0-alpha.1`（versionCode 2），协议为 DST1 v1，数据库为 Room v5。完整进度见[实施状态与路线图](android-phase-1-summary-and-roadmap.md)。

## 已具备

- 严格解析、预览并以单事务导入 DST1；
- 持久化 Dom、批次、积分组、任务定义、实例、步骤和执行进度；
- 支持普通、步骤、计数、计时、信息告知和重复任务；
- 支持完成、撤销、未完成校准、积分流水和每日结果重算；
- 支持延期、重新开启、跨积分组迁移和显式日期迁移；
- 支持既有 `h` 的本地隐私通知、权限控制和系统事件重建；
- 提供今日分类、任务详情、完整执行及导入流程。
- 提供历史分页、搜索筛选、月历、日期结果和复用的只读任务详情。
- 提供当前任务日结果、纯文本复制、结果长图和信息告知分享。
- 提供“我的”积分概览、趋势、完成率、分类统计、积分组归档和积分流水。
- 提供“我的”右上角设置入口、明暗模式、“靛紫 / 晴空”内置配色选择、减少动效、通知管理、分享隐私重置和版本信息。
- 提供 Navigation Compose 与自定义覆盖层的预测式返回，并统一全部 UI 返回入口。
- 提供 DSTB1 本地备份、预览、合并/替换恢复、完整性检查和失败回滚。
- 提供本地诊断导出、隐私与许可页面、签名 Release 和 GitHub Releases 分发。

## 未纳入当前 Android 版本

- Dom 任务生成网页；
- Google Play 分发；
- 账号、云同步、联网更新和遥测。

能力从“未实现”变为“已实现”不要求升级 DST1；只有线格式或业务语义出现不兼容变化时才升级协议主版本。

## 持久化兼容

Room 当前为 v5，并提供 `1→2→3→4→5` 显式迁移。v4 的业务结构见[数据库规范](android-database-v4.md)，v5 新增的统计索引见[W25 实现说明](w25-profile-statistics.md#数据库与数据边界)。后续结构变更必须同时提交连续 migration、导出 Schema和数据保留测试，并更新相应数据库文档。
