# W24 今日结果与分享实现说明

> 前置：W10、W12、W22、W23
> 协议：保持 `DST1` / `v=1`
> 数据库：保持 Room v1.4

## 今日结果

- 今日列表位于顶部时继续下拉，达到 96dp 后松手展开结果页；为 TalkBack 提供“查看今日结果”自定义操作；
- 打开前使用现有实例生成服务校准截止状态，然后一次性读取 W12 `ResultRepository` 快照；
- 结果页打开后保持任务日和结果快照，跨凌晨 4 点也不自动替换；返回今日页后再刷新；
- 页面展示 Dom 名称（若有）、中文完整日期、全局状态、本日净积分、积分组状态/净积分、任务状态和组结果文案；
- 排除未开始和已撤销实例；任务行不可点击，不显示来源、截止时间、进度、描述、备注、告知正文或内部 ID；
- 分组和任务排序与今日页一致，未分组区位于最后；零积分明确显示 `0`；
- 空结果、读取错误和重试均使用用户文案，不暴露内部异常；
- 结果页滚动到末尾后继续上滑 72dp 才关闭，系统返回可直接关闭；
- “复制结果”生成固定纯文本，“分享图片”进入图片预览。

## 图片生成与分享

- 使用固定 1080px 宽浅色 PNG、固定导出字号和当前应用主题色；页面采用连续成绩单版式，顶部优先展示必做任务完成数、状态和次级积分；
- 状态同时使用文字与蓝/橙/红/灰语义色，不依赖颜色表达；
- 图片高度随内容增长，不分页、不截断；超过 32,000px 或 128MiB 位图预算时拒绝生成并建议复制结果；
- 结果图默认展示全部任务；预览可切换为“仅未完成”，此时保留待完成和未完成任务、隐藏空分组，全部完成时生成紧凑完成卡片；
- 预览按屏幕宽度适配：图片不足一屏时上下视觉居中，超过可用高度时纵向滚动；支持双指缩放和双击放大；“发送给其他应用”为主操作，“保存到相册”为次操作；
- 系统分享仅发送图片，不附加文字；缓存图片通过 `FileProvider` 提供临时只读 URI；
- Android 10+ 使用 `MediaStore` 保存至 `Pictures/DST Sub`，Android 8–9 使用系统“另存为”；
- 图片使用可读建议文件名，由系统处理同名冲突，不加入应用水印或生成时间；
- 未新增相册、存储或网络权限。

## 信息告知分享

- 今日任务详情与历史只读详情都提供“复制正文”和“分享图片”；
- 任何状态只要存在非空正文即可分享；待完成任务会先立即保存当前草稿，但分享不会完成任务；
- 复制只包含正文并保留内部换行；
- 告知图只包含任务标题、信息告知类型、归属日期、Dom 名称（若有）和完整正文；任务标题为主层级，正文采用信笺版式；
- 首次保存或发送告知图时提示内容隐私，确认状态保存在轻量本地偏好中；
- 历史页不提供历史日期整日结果图。

## 数据边界

- `ResultTaskRow` 和 `DailyResultSnapshot` 增加只读展示元数据，包括名称、排序、积分组名称及 Dom 名称；
- 结果状态、实际净积分和组文案仍由 W12 计算器与仓储提供，UI 不重算业务规则；
- DST1 Schema、Room 表结构和迁移均无变化。
