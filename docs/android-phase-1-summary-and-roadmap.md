## 依赖顺序

```text
W21 通知 ───────────────┐
W22 今日执行 UI ────────┼─→ W32 发布加固
W23 历史 UI ──────┐     │
W24 结果与分享 ───┼─→ W30 统计
```

W22、W23、W24 可并行，但只能消费领域服务，不能在 UI 重写状态、积分或结果规则。

## 后续窗口

### W21：本地通知

- 开放 DST1 `h`；
- 实例发布后生成提醒记录；
- 处理权限、重启、时间和时区变化；
- 使用隐私通知，不申请精确闹钟和网络权限；
- 通知失败不影响任务执行。

验收：重复核对不重复提醒，过期提醒不补发，拒绝权限不破坏其他功能。

### W22：今日执行 UI

- 按每日、每周、临时和积分组分类；
- 接入步骤、计数、计时、信息告知、完成与撤销；
- 提供折叠、加载、错误和空状态；
- Composable 不直接访问 DAO。

验收：所有交互只调用 W10/W11/W20 服务，旋转或重建不丢持久化进度。

### W23：历史页面

- 按任务日倒序、日历跳转、搜索和筛选；
- 显示实例快照、进度、日志和结果修订；
- 普通备注可编辑，信息正文只读。

验收：大范围历史查询无逐实例 N+1，历史数据不被最新定义覆盖。

### W24：今日结果与分享

- 展示当前任务日全局和分组结果；
- 今日页下拉结果；
- 生成动态长图、复制文本和系统分享；
- 排除备注、描述、正文和内部 ID。

验收：页面和分享内容均来自 W12 `ResultRepository`。

### W30：“我的”统计

- 累计、本日、7 日和 30 日积分；
- 必做完成率、积分组和任务分类统计；
- 流水及归档积分组入口。

验收：统计由业务记录聚合，缓存不是恢复后的最终依据。

### W31：DSTB1 备份与恢复

- UTF-8、zlib、CRC32 和版本化文件头；
- 系统文件选择器导入导出；
- 完全替换、失败回滚和按 ID 合并；
- 通知不备份，恢复后重建。

验收：损坏文件不修改现有数据，完全替换失败可自动恢复。

### W32：发布加固

- migration 全链路、性能和恶意输入测试；
- 真机/模拟器、通知、重启和时区测试；
- Compose 无障碍、字体缩放和主题检查；
- Manifest、权限、隐私和发布构建审核。

验收：无破坏性迁移、无 `INTERNET` 权限、发布构建和关键仪器测试通过。

## 窗口统一交付标准

每个窗口必须：

1. 先更新契约或领域规则，再实现；
2. 保持预览与正式执行共用规划器；
3. 跨 DAO 写入使用一个 Room 事务；
4. 定义幂等、回滚和审计行为；
5. 同步测试和直接相关文档；
6. 运行：

```powershell
./gradlew.bat testDebugUnitTest assembleDebug
git diff --check
```

交接只需报告：完成项、刻意后置、协议/数据库变化、主要文件、测试结果和已知风险。
