# W23 历史页面实现说明

> 前置：W10、W11、W12、W20、W22
> 协议：保持 `DST1` / `v=1`
> 数据库：Room v4，新增 `3→4` migration

## 已实现

- 历史页按任务日倒序分页，每次加载 30 个有记录日期，并包含当前任务日；
- 支持任务名称、导入时的积分组名称快照和普通备注搜索，输入停止 300ms 后查询；
- 支持待完成、已完成、未完成、已撤销，以及必做/选做、每日/每周/临时组合筛选；
- 月历以圆点标记存在记录的日期，可查看精确日期；空日期可跳转到上一条记录；
- 日期卡展示结果、完成数、净积分和任务摘要；截止时间始终显示完整日期与分钟，整点显示 `:00`；
- 日期详情展示全局/积分组结果、任务列表和结果修订；
- 历史任务详情复用今日任务详情 Composable 的只读模式，隐藏步骤、计数、计时、告知正文和完成/撤销操作，仅普通备注保持可编辑；
- 普通备注与今日详情共享同一记录，停止输入 500ms 后自动保存，离页时立即提交；
- 操作与修订时间线只展示面向用户的状态、动作和时间，不暴露内部代码或记录 ID。
- 操作与结果修订按原始毫秒时间倒序排列；即使显示时间处于同一分钟，新记录也保持在上方。
- 结果修订的积分文案明确标注每日积分、具体积分组名称或未分组积分。

## 查询与快照

- `task_instance.groupNameSnapshot` 保存实例发布或导入时的积分组名称，避免历史被后续改名覆盖；
- `3→4` migration 会从现有 `task_group` 回填仍可关联实例的名称；
- 日期页先批量查询日期汇总，再按本页日期集合一次性加载任务、备注和进度摘要，不逐实例查询；
- 10,000 条实例数据集测试覆盖 30 日分页和组合筛选。

## 状态与结果文案

| 数据状态 | 页面文案 |
| --- | --- |
| `NOT_STARTED` / `PENDING` | 待完成 |
| `COMPLETED` | 已完成 |
| `MISSED` | 未完成 |
| `CANCELLED` | 已撤销 |
| `COMPLETED` 日结果 | 全部完成 |
| `IN_PROGRESS` 日结果 | 尚未完成 |
| `INCOMPLETE` 日结果 | 有任务未完成 |
| `OPTIONAL_ONLY` 日结果 | 仅有选做任务 |
| 无日结果 | 暂无结果 |
